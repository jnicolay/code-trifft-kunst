📖 Kleines JavaScript-Tutorial mit Beispielen

1. Welche Fläche? Mit if (flaeche === 0) reagierst du auf Fläche 1 (0, 1 und 2).

2. Start und Loslassen: beruehrungStart(flaeche) und beruehrungEnde(flaeche) bestimmen die Aktionen.

3. Sample-Ausschnitt: sampleSegment(0, 2, 0.8) startet Sample 1 bei Sekunde 2 und spielt 0,8 Sekunden. Für diese Beispiele den Mischpult-Spielmodus der Fläche auf „JavaScript-Code“ setzen.

function beruehrungStart(flaeche) {
  if (flaeche === 0) {
    sampleSegment(0, 1.5, 0.6);
  }
  if (flaeche === 1) {
    sampleRandomPitch(1);
  }
}
function beruehrungEnde(flaeche) {
  if (flaeche === 0) sampleStop(0);
}

Weitere Befehle: sampleStart(0), sampleLoop(0), sampleDelay(0,0.3,0.4), sampleReverb(0,0.5), samplePitch(0,1.5), sampleFilter(0,900), sampleFadeOut(0,1).

Ablauf: Code bearbeiten → „JavaScript-Programm starten“ → Spielmodus „JavaScript-Code“ → Testen → Projekt exportieren.

⚙️ Touchflächen kalibrieren / Technik-Hilfe

1. Verbinde deinen Laptop oder dein Handy mit dem WLAN des ESP32 (Name etwa Klangbild-XXXX, Passwort klangbild123).

2. Öffne http://192.168.4.1 im Browser. Ohne Internet ist bei diesem WLAN normal.

3. Schließe alle Kabel und getrockneten Farbflächen an. Niemand berührt die Flächen. Dann kalibrieren.

Kalibrierung funktioniert nur direkt über das ESP-WLAN.

Rohwerte erscheinen nach der Verbindung.
